# Vum VPN — Security Policy

## Reporting a Vulnerability

This repository holds public distribution files and documentation only — the
backend and the client sources live in a private repository. Vulnerabilities
anywhere in the ecosystem are still very much in scope.

If you find a security issue in Vum VPN (Android client, Windows client, bot,
website or backend infrastructure), **please do not publish it publicly.**

Email the security team: **security@ghostcore.io**

Or reach us over Telegram: [@ghostcore_support](https://t.me/ghostcore_support).

### What to include

- Type of vulnerability (XSS, SQLi, IDOR, buffer overflow, …)
- Step-by-step reproduction
- Proof of concept: script, code or screenshots
- Affected platform (Android app, Windows app, website, Telegram bot)
- Potential impact

### What happens next

1. We acknowledge your report within 48 hours.
2. We investigate and assess severity.
3. Once confirmed, we work on a patch and agree a disclosure timeline with you.
4. Reports that lead to a significant fix may be eligible for a bounty.

## Bug Bounty

We pay bounties for responsibly reported critical and high-severity issues. The
amount depends on severity and on the quality of the report.

### Out of scope

- Volumetric attacks (DoS, DDoS)
- Social engineering and phishing
- Findings without a demonstrable security impact
- Anything requiring physical access to an unlocked device

Thank you for helping keep Vum VPN safe.
